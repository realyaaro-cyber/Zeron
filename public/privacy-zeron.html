Privacy Policy

This policy explains how ZERON handles information when you use our Discord bot and associated dashboard.

01 / OVERVIEW

About this policy

ZERON is a Discord bot and related dashboard designed to provide community tools and server features. This policy applies to information processed through those services.

By using ZERON, you acknowledge that information may be processed as described here. If you do not agree, you can stop using the bot and dashboard.

02 / INFORMATION

Information we may collect

Depending on which features your server uses, ZERON may process:

  • Discord identifiers: user IDs, server IDs, and identifiers needed to operate features.
  • Server settings: configuration values selected by authorized server managers.
  • Progress and economy data: XP, levels, virtual balances, inventory, achievements, and related transactions when those features are used.
  • Moderation records: action details, moderator and target identifiers, and reasons where the relevant feature records them.
  • Dashboard account information: information made available through Discord OAuth when you sign in, such as your Discord account ID and basic profile information used by the dashboard.
  • Technical information: information processed by Discord or the hosting environment to operate, secure, and troubleshoot the service.

The exact information processed depends on the features enabled and how you interact with ZERON. We do not intend to request Discord passwords or your Discord authentication tokens.

03 / PURPOSE

How information is used

  • Provide bot commands and dashboard functionality.
  • Maintain server settings, levels, virtual economy features, and game progress.
  • Support moderation and server administration features.
  • Protect the service, enforce limits, investigate errors, and prevent abuse.

ZERON's virtual economy is for in-service use. Virtual balances are not real money unless explicitly stated otherwise.

04 / THIRD PARTIES

When information is shared

ZERON does not need to sell personal information to operate its advertised features. Information may be processed or shared with the following services when necessary:

  • Discord: account authentication, bot operation, and communication with Discord servers.
  • Hosting and infrastructure providers: to run and protect the bot and dashboard.
  • Legal and safety requests: where disclosure is required by applicable law or reasonably necessary to protect rights and safety.

Server members should also consider that information posted in Discord channels may be visible to other server members according to that server's permissions and settings.

05 / SECURITY

Storage and security

ZERON uses a database to maintain certain bot features and server records. Dashboard authentication uses Discord OAuth and server-side sessions.

Reasonable safeguards should be used to protect application data and credentials. However, no online service or storage system can be guaranteed completely secure.

Access to server data through dashboard features is subject to authentication and the relevant Discord permissions.

06 / RETENTION

Data retention and deletion

Information may remain in the database while needed to operate features, maintain server settings, preserve progress, or address security and operational issues. Actual retention can vary by record type and current implementation.

If you want data associated with your Discord account or server reviewed for deletion, contact the service operator using the contact method published for ZERON. Include the relevant Discord user or server ID where appropriate, but never send passwords or authentication tokens.

Some information may need to be retained for legitimate operational or legal reasons. Removing a bot from a server or disconnecting your account may not automatically erase every stored record.

07 / YOUR CHOICES

Your choices

  • You can stop using ZERON's commands.
  • Authorized server administrators can review which ZERON features their server uses.
  • You can remove ZERON from a server if you no longer want it there.
  • You can request information about or deletion of eligible stored data through the published support contact.

Depending on where you live, local privacy laws may give you additional rights. Requests may require reasonable verification before action is taken.

08 / AGE

Children's privacy

ZERON is not intended to bypass Discord's age requirements or applicable laws protecting children. Users should meet the minimum age required by Discord and the laws applicable to them.

If you believe a child has provided information inappropriately, contact the service operator through the published support channel.

09 / UPDATES

Changes to this policy

This policy may be updated when ZERON's features, data practices, or legal obligations change. The effective date at the top will be updated when a revised policy is published.

10 / CONTACT

Questions or privacy requests

For privacy questions, access requests, or deletion requests, contact the ZERON service operator through the official ZERON support channel.
